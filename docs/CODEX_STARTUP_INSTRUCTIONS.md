# Starting work

Read AGENTS.md, the project handbook, master blueprint, roadmap and current status. Verify the AgentFlow checkout, preserve local edits and confirm the baseline relevant to the task. Use the local setup and test commands in README.md and docs/database.md. Review pending migrations before applying them. For assistant acceptance follow AGENTFLOW_CURRENT_PROJECT_STATUS.md. Restrict implementation and Git writes to AgentFlow.

For workspace, assistant or platform administration changes, consult [competitor research](AGENTFLOW_COMPETITOR_RESEARCH.md), [the gap analysis](AGENTFLOW_PRODUCT_GAP_ANALYSIS.md), [the owner journey](AGENTFLOW_UX_UI_BENCHMARK.md) and [design conventions](AGENTFLOW_DESIGN_SYSTEM.md). Check current code and provider evidence before changing product status.

Use Relevance AI as a primary reference for workforce management and agent configuration. Check public sources before adopting an interaction. When consulting OnPlas, compare the local revision with its current remote HEAD; use an isolated read-only reference snapshot when needed. Keep all implementation in AgentFlow.
